- 修复 Nano Banana 尺寸/宽高比不生效：选择 Nano Banana（Gemini Flash Image）系列模型并指定宽高比（如 3:2）时，生成图仍固定 1024×1024 的问题。经真机实测上游（New-API OpenAI 兼容透传）确认：Nano Banana 只认 OpenAI 标准的**像素级 `size`（如 `1248x832`）并精确遵循**（实测 3:2/9:16、1K~4K、自定义、超大尺寸均精准命中），而**比例字符串 `3:2`、`aspect_ratio`、`image_size`、`quality` 全部无效**。修复后 Nano Banana 请求改为只透传像素级 `size`（由分辨率档 + 宽高比或自定义尺寸合成），不再发比例字符串或 quality。因 Nano Banana 上游可精确出图到 6000×4000 级、支持真 4K，为其单独放宽尺寸上限（最长边 5504、像素上限 2400 万、4K 基数 4096），因此 Nano Banana 的 4K 档现在能输出真 4K（如 1:1→4096×4096、16:9→5456×3072、3:2→5008×3344，均已真机验证），而其它模型（gpt-image 等）仍沿用原上限（4K 最长边 3840，如 gpt-image 1:1→2880×2880），不受影响。此外由于质量参数对 Nano Banana 完全无效，生图工作台在选中 Nano Banana 系列模型时**保留「质量」挡位但整体置灰不可点击**（标题显示「质量（当前模型不支持）」），切换回其它模型（gpt-image 等）质量挡位恢复可选。需验证：Nano Banana 选 3:2 / 16:9 / 9:16 等比例时生成图实际按对应像素尺寸返回，4K 档达到真 4K，自定义尺寸精确遵循，质量字段不影响尺寸，且请求不出现 `aspect_ratio`、`image_size`。
